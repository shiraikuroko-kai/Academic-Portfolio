# Academic & Project Portfolio

Welcome to my academic and project portfolio.

It is designed to showcase:  
-  Technical skills
-  Problem-solving approaches
-  Growth as an analyst and project leader


##  My Journey and Project Timeline

###  Teddy Cup (2020)
One of my earliest independent data mining projects.  
- Learned the end-to-end workflow: data cleaning, NLP preprocessing, TF-IDF, and PageRank (from scratch).  
- Key lesson: importance of data quality and reproducible code.  
- Recognition: earned Provincial Winner award.  

---

###  Student Platform (2022–2023)  
My first real taste of leadership.  
- Role: Project Manager for a university-level initiative.  
- Focus: not just coding, but system architecture, team coordination, and workflow improvement.  
- Applied Agile methodology to resolve bottlenecks and successfully delivered a functional MVP.  

---

### 📖 Thesis Analysis (2023–2024)  
The culmination of my undergraduate academic training.  
- Initial version: early 2023 (basic NLP models).  
- Refactored in 2024 after self-study: integrated LDA topic modeling and cleaner design.  
- This project reflects my commitment to continuous improvement and academic rigor.  

---

###  Pandemic Simulator (2024–Present)  
My most ambitious and independent project so far.  
- Inspired by a complex systems lecture at Beijing Normal University.  
- Built an interactive, agent-based epidemic simulator using Python and Pygame.  
- Features: adjustable parameters (population density, infection rates) with real-time visualization.  
- Represents my interest in **systems modeling, simulation, and interactive tools.
